# FAQ — аддон «Профиль игрока» (Enterum/CharacterProfile)

**Версия документа:** 1.0.3  
**Платформа:** XenForo 2.2+

Краткие ответы на частые вопросы администраторов, модераторов и игроков.

---

## О плагине

### Что делает этот аддон?

Добавляет в профиль пользователя XenForo две вкладки:

- **Репутация** — очки героизма (ОГ) и репутация по биомам (Арамидис, Корзус, Юнион).
- **Рюкзак** — предметы за активности, созданные предметы и текстовый блок «Прочее».

Дополнительно в ACP есть **журнал действий** — кто и когда менял данные профиля.

### Где вкладка «Лист персонажа»?

В текущей версии **скрыта** в интерфейсе. Функционал запланирован на v2. Прямой URL (`members/{id}/character-sheet`) пока ведёт на заглушку.

### Какие требования к серверу?

- XenForo **2.2.0** или новее  
- PHP **7.2.0** или новее  

---

## Кому видны вкладки

### У кого в профиле появляются вкладки «Репутация» и «Рюкзак»?

Одновременно должны выполняться **три условия**:

1. Пользователь состоит в **группе-триггере** (по умолчанию группа с ID **16**).
2. У **посетителя** (кто смотрит профиль) есть право `character_profile.view`.
3. Профиль доступен для просмотра в XenForo (нет блокировки профиля и т.п.).

### Как настроить группу-триггер?

**ACP → Настройки → Опции → Профиль игрока → ID группы-триггера**

Обычно это группа «Принятые игроки с анкетой». Можно указать другой ID.

### Игрок получил группу, но вкладок нет

Проверьте по порядку:

1. ID группы в опциях совпадает с группой игрока (основная или дополнительная).
2. Посетителю выдано право **view** (в т.ч. гостям, если вкладки должны видеть все).
3. Выполнено **обновление аддона** и **пересборка кэша**.
4. Откройте профиль в режиме инкогнито / под другим аккаунтом — возможно, у вашей группы нет **view**.

### Игрока сняли с группы-триггера. Данные пропадут?

**Нет.** Записи в базе остаются. Вкладки просто **скрываются**. При повторной выдаче группы данные снова отображаются.

### Гости могут смотреть вкладки?

Да, если группе **Гости** (или «Незарегистрированные») выдано право **view**.

## Установка и обновление

### Как установить аддон?

Через **FTP**:

1. Скопировать папку `upload/src/addons/Enterum/CharacterProfile/` на сервер в  
   `src/addons/Enterum/CharacterProfile/`.
2. Убедиться, что **нет** файла `hashes.json` в папке аддона.
3. **ACP → Аддоны → Установить**.
4. **Инструменты → Пересборка кэша**.

Подробно: [INSTALL_PROD_RU.md](INSTALL_PROD_RU.md)

### Как обновить аддон?

1. Заменить файлы в `src/addons/Enterum/CharacterProfile/` новой версией.
2. Удалить `hashes.json`, если он появился.
3. **ACP → Аддоны → Обновить** → пересборка кэша.

### Ошибка «отсутствуют N файлов» при установке

На сервере лежит **`hashes.json`**. При установке через FTP он не нужен.

**Решение:** удалить `src/addons/Enterum/CharacterProfile/hashes.json` и повторить установку.

### Ошибка Could not find class … XF\Entity\User

Файлы аддона загружены не полностью или не в ту папку.

Проверьте наличие:
```
src/addons/Enterum/CharacterProfile/XF/Entity/User.php
```

Не должно быть вложенности `.../CharacterProfile/upload/src/addons/...`.

На Linux важен **регистр** папок: `Admin`, `Pub`, `XF` — с заглавной буквы.

## Права доступа

### Где настраиваются права?

**ACP → Группы и права → Права пользователей → Профиль игрока**

### Краткая таблица прав

| Право | Для кого | Что даёт |
|-------|----------|----------|
| **view** | Все (в т.ч. гости) | Просмотр вкладок у игроков с группой-триггером |
| **manageHero** | Модераторы | Добавление, правка и удаление записей ОГ |
| **manageHeroSupport** | Админы | Запись «Получено за поддержку» в журнале ОГ |
| **manageReputation** | Модераторы | Журнал репутации по биомам |
| **manageBackpack** | Модераторы | Предметы за активности и созданные предметы |
| **manageBackpackOwn** | Игроки | Редактирование только **своего** блока «Прочее» |
| **viewLogs** | Доверенные модераторы | Просмотр журнала в ACP |
| **manageCharacterSheet** / **Own** | — | Зарезервировано для v2 |

**Admin permission** `characterProfile` — доступ к разделу «Профиль игрока» в ACP.

### Игрок видит вкладки, но не может ничего редактировать

Это нормально. По умолчанию игрок **только смотрит**. Редактирование:

- ОГ и репутация — только **manageHero** / **manageReputation** / **manageBackpack**.
- Блок «Прочее» — **manageBackpackOwn** (свой профиль) или **manageBackpack** (любой).

### Модератор не видит кнопки редактирования

Выдайте нужное право из таблицы выше и пересоберите кэш прав.

## Очки героизма (ОГ)

### Где смотреть и редактировать ОГ?

Профиль игрока → вкладка **Репутация** → блок «Актуальное количество Очков Героизма».

### Сколько максимум ОГ можно иметь?

По умолчанию **3** (настраивается: **ACP → Опции → Максимум очков геройства**).

### Что такое «сгорание» (overflow)?

Если игрок получает ОГ сверх лимита, лишнее **не накапливается** — фиксируется как переполнение. Итоговое отображаемое значение не превышает максимум.

### В каком порядке записи в журнале ОГ?

От **старых к новым** — новые записи добавляются **внизу** списка.

### Что нужно указать при добавлении ОГ?

- Дата (формат `дд.мм.гггг`)
- Тип: получено / потрачено
- Количество (от 1 до 3)
- Ссылка и название ссылки (кроме записей «за поддержку»)

### Кто может отмечать «Получено за поддержку»?

Только пользователи с правом **manageHeroSupport**.

## Репутация по биомам

### Где находится репутация?

Профиль → **Репутация** → раздел ниже блока ОГ.

### Какие регионы поддерживаются?

**Арамидис**, **Корзус**, **Юнион** — переключаются вкладками внутри страницы.

### Кто может добавлять записи репутации?

Пользователи с правом **manageReputation**.

### Что отображается кроме журнала?

- Сводная таблица влияния по биому  
- Отношения с фракциями (в спойлерах)  
- Пагинация длинных списков

## Рюкзак

### Какие подвкладки есть?

1. **Предметы за активности** — награды за квесты, БМ и т.д.  
2. **Созданные предметы** — крафт с указанием автора и ссылки на заявку.  
3. **Прочее** — произвольный текст с BB-кодом.

### Кто редактирует предметы?

**manageBackpack** — активности и созданные предметы у **любого** игрока.

### Кто редактирует «Прочее»?

- **manageBackpackOwn** — только **свой** профиль.  
- **manageBackpack** — любой профиль.

### Как редактировать «Прочее»?

Рюкзак → **Прочее** → **Редактировать** → редактор BB-кода (как при написании сообщения на форуме) → **Сохранить**.

### Как указать автора созданного предмета?

В форме добавления начните вводить **@ник** — появится подсказка с пользователями форума.

## Журнал действий (ACP)

### Где смотреть историю изменений?

**ACP → Профиль игрока → Логи действий**

### Что попадает в журнал?

Добавление, изменение и удаление:

- записей ОГ  
- записей репутации  
- предметов рюкзака  
- блока «Прочее»  

### Журнал пустой

1. Проверьте опцию **Включить логирование** (ACP → Опции → Профиль игрока).  
2. Сделайте тестовое изменение (например, добавьте ОГ).  
3. Убедитесь, что аддон обновлён и таблица `xf_char_profile_action_log` создана.

### Кто может открыть журнал в ACP?

Нужны:

- admin permission **characterProfile**, и  
- статус супер-админа / админа форума **или** право **viewLogs**.

## Типичные сценарии

### Приняли нового игрока на форум

1. Выдайте группу-триггер (например, ID 16).  
2. Строка профиля создаётся автоматически.  
3. Вкладки появляются в профиле (если у зрителей есть **view**).

### Модератор выдал ОГ за квест

1. Право **manageHero**.  
2. Профиль игрока → Репутация → форма в блоке ОГ.  
3. Заполнить дату, количество, ссылку на квест → сохранить.

### Игрок описал снаряжение в «Прочее»

1. Право **manageBackpackOwn**.  
2. Рюкзак → Прочее → Редактировать → BB-код → Сохранить.

### Нужно узнать, кто изменил репутацию

1. ACP → Логи действий.  
2. Фильтр: тип «Репутация», ник профиля или автора изменения.

## Устранение неполадок

| Проблема | Что проверить |
|----------|----------------|
| Нет вкладок в профиле | Группа-триггер + право **view** |
| 404 на страницах репутации/рюкзака | Обновить аддон, пересобрать маршруты и кэш |
| Нет кнопок «Редактировать» | Права **manage*** для нужной группы |
| «Прочее» не сохраняется | **manageBackpackOwn** или **manageBackpack** |
| Старый вид после обновления | Пересборка кэша шаблонов и CSS, Ctrl+F5 |
| Ошибка колонок «Прочее» в БД | Обновить аддон в ACP (upgrade-шаги схемы) |
| ACP не открывается после сбоя | Отключить class extension `Enterum\CharacterProfile\XF\Entity\User` в БД |
