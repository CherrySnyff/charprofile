# Как пользоваться аддоном «Профиль игрока»

Аддон **Enterum/CharacterProfile** для XenForo 2.2 добавляет в профиль пользователя вкладки **Репутация** и **Рюкзак**. Вкладка **Лист персонажа** скрыта до v2.

**Текущая версия:** 1.0.3

Подробные ответы на частые вопросы: [FAQ_RU.md](FAQ_RU.md)

---

## 1. Установка и обновление

1. Скопируйте папку `upload/src/addons/Enterum/CharacterProfile/` на сервер в  
   `src/addons/Enterum/CharacterProfile/` (через FTP).
2. Убедитесь, что в папке аддона **нет** файла `hashes.json`.
3. В **ACP → Аддоны** найдите «Профиль игрока» → **Установить** или **Обновить**.
4. **Инструменты → Пересборка кэша** (шаблоны, права, маршруты).

Подробная инструкция: [INSTALL_PROD_RU.md](INSTALL_PROD_RU.md)

---

## 2. Настройки (ACP → Опции → Профиль игрока)

| Опция | По умолчанию | Назначение |
|-------|--------------|------------|
| **ID группы-триггера** | 16 | Пользователи в этой группе получают вкладки и строку в `xf_char_profile` |
| **Максимум очков геройства** | 3 | Лимит отображаемых ОГ (точки) |
| **Включить логирование** | Да | Запись add/edit/delete в журнал |
| **Записей на странице** | 50 | Пагинация списков и ACP-логов |

---

## 3. Права (ACP → Группы и права → Права пользователей)

Группа прав: **character_profile**.

| Право | Кто обычно получает | Что даёт |
|-------|---------------------|----------|
| **view** | Все, включая гостей (по желанию) | Просмотр вкладок у игроков с группой-триггером |
| **manageHeroOwn** | Игроки | ОГ **только в своём** профиле |
| **manageReputationOwn** | Игроки | Репутация **только в своём** профиле |
| **manageBackpackOwn** | Игроки | Рюкзак (все подвкладки) **только в своём** профиле |
| **manageHero** | Модераторы, админы | ОГ **любого** игрока |
| **manageHeroSupport** | Админы | Галочка «Получено за поддержку» |
| **manageReputation** | Модераторы | Журнал репутации **любого** игрока |
| **manageBackpack** | Модераторы | Рюкзак **любого** игрока |
| **manageCharacterSheet** | Модераторы | (v2) Лист любого игрока |
| **manageCharacterSheetOwn** | Игроки | (v2) Свой лист |
| **viewLogs** | Доверенные модераторы | Просмотр журнала в ACP |

**Admin permission:** `characterProfile` — доступ к разделу «Профиль игрока» в ACP.

---

## 4. Когда появляются вкладки

- Пользователь состоит в **группе-триггере** (по умолчанию ID **16** — «Принятые игроки с анкетой»).
- У посетителя есть право **view**.
- Профиль пользователя доступен для просмотра в XenForo.

При **снятии** группы вкладки скрываются, **данные в БД остаются**. При повторной выдаче группы вкладки снова видны.

---

## 5. Вкладка «Репутация»

### Очки геройства (ОГ)

- Отображаются **точками** (макс. 3).
- Журнал в две колонки; операции: **получение**, **потеря**, **поддержка**.
- При переполнении лимита — сгорание лишнего (overflow).
- Модератор с **manageHero** добавляет записи через форму внизу блока ОГ.

### Репутация по регионам

- Вкладки регионов: Арамидис, Корзус, Юнион.
- Таблица влияния, отношения фракций (спойлеры).
- **manageReputation** — добавление/правка/удаление записей в журнале.

**URL:** `members/{user_id}/reputation`

---

## 6. Вкладка «Рюкзак»

Три подвкладки:

### Предметы за активности

- Название, тип, уровень, редкость, ссылка, причина.
- CRUD для **manageBackpack**.

### Созданные предметы

- Название, тип, уровень, заявка, автор (@ник с автодополнением).
- CRUD для **manageBackpack**.

### Прочее

- Текстовый блок с **BB-кодом** (как описание в guildM).
- Редактирование: **manageBackpack** (любой профиль) или **manageBackpackOwn** (только свой).

**URL:** `members/{user_id}/backpack?sub=activity|crafted|other`

---

## 7. Вкладка «Лист персонажа»

В UI **скрыта** до v2 (ссылки убраны из навигации). Маршрут и заглушка сохранены для будущей разработки.

**URL (прямой):** `members/{user_id}/character-sheet`

---

## 8. Журнал действий (ACP)

**ACP → Профиль игрока → Логи действий**

- Все изменения ОГ, репутации, рюкзака (add / edit / delete).
- Фильтры: тип, действие, ник профиля, автор изменения, даты.
- Вкладки по типу контента.
- Пагинация.

**Кто видит:** администраторы с permission `characterProfile` и (супер-админ / админ / **viewLogs**).

## 9. Архитектура кода (для разработчиков)

```
Enterum/CharacterProfile/
├── Admin/Controller/Logs.php      — ACP: журнал действий
├── Pub/Controller/                — публичные страницы и POST-действия
│   ├── AbstractProfileAction.php  — база: пользователь, права, шаблон
│   ├── Reputation.php, Hero.php   — просмотр и мутации ОГ
│   ├── ReputationLog.php          — мутации репутации
│   ├── Backpack*.php              — рюкзак и подразделы
│   └── CharacterSheet.php         — заглушка листа
├── Service/
│   ├── PermissionGuard.php        — единая точка проверки прав
│   ├── ProfileInitializer.php     — группа 16 → строка профиля
│   ├── ActionLogger.php           — запись в xf_char_profile_action_log
│   ├── Hero/HeroPointManager.php
│   ├── Reputation/*
│   └── Backpack/*
├── Entity/                        — ORM-сущности таблиц xf_char_profile_*
├── Repository/                    — выборки для списков
├── Helper/                        — BB-код, схема «Прочее», формат логов
├── Listener/                      — группа пользователя, шаблоны профиля
├── Setup.php                      — install / upgrade / uninstall
└── _data/                         — XML: routes, permissions, templates, phrases
```

**Таблицы БД:**

- `xf_char_profile` — одна строка на игрока, кэш ОГ, блок «Прочее»
- `xf_char_profile_hero_log` — журнал ОГ
- `xf_char_profile_reputation_log` — журнал репутации
- `xf_char_profile_backpack_activity_item` / `_crafted_item` — рюкзак
- `xf_char_profile_action_log` — аудит изменений

## 10. Типичные сценарии

### Новый принятый игрок

1. Выдать группу **16** (или вашу группу-триггер).
2. Строка профиля создаётся автоматически (listener + initializer).
3. Вкладки появляются в профиле.

### Модератор выдаёт ОГ

1. Право **manageHero**.
2. Профиль игрока → Репутация → форма в блоке ОГ.
3. Запись появляется в ACP-логах.

### Игрок заполняет «Прочее»

1. Право **manageBackpackOwn**.
2. Рюкзак → Прочее → редактировать → BB-код → сохранить.

### Проверка, кто что менял

1. ACP → Профиль игрока → Логи действий.
2. Фильтр по нику или типу `hero` / `reputation` / `backpack_*`.

## 11. Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Нет вкладок | Проверить группу-триггер и право **view** |
| 404 на вкладках | Пересобрать маршруты и кэш аддона |
| Нет кнопок редактирования | Выдать соответствующее **manage*** право |
| Пустой журнал в ACP | Включить «Включить логирование»; сделать тестовое изменение |
| Ошибка колонок «Прочее» | Обновить аддон в ACP (upgrade steps 22–24) |
